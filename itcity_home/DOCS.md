# ITCITY Home

Дашборд у стилі Homey для Home Assistant.

- **Дім** — привітання, погода, зведення (освітлення, охорона, енергія, клімат, котел, батарейки), графік відключень світла, вибрані пристрої.
- **Кімнати** — усі пристрої за поверхами й кімнатами з HA.
- **Картка пристрою** — вкладки «Керування», «Параметри», «Графіки» (Г/Д/Т/М/Р), «Автоматизації», «Історія».
- **Енергія** — лічильник по фазах, облік день/ніч, вартість.

Відкривається з бокового меню HA («Дім»). Додати у вибране — ♥ у картці пристрою.
