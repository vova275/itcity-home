# ITCITY Home

Зручний дашборд для **Home Assistant** у стилі застосунків розумного дому: кімнати, квадратні плитки, а тап по плитці відкриває картку пристрою з вкладками.

- 🏠 **Дім** — привітання, погода, зведення, графік відключень світла (інтеграція `ukraine_outages`), вибрані пристрої
- 🧱 **Кімнати** — пристрої з реєстру HA, згруповані за поверхами й кімнатами
- 🎛 **Картка пристрою** — Керування · Параметри · Графіки (година/доба/тиждень/місяць/рік) · Автоматизації · Історія
- ⚡ **Енергія** — лічильник по фазах, облік день/ніч у кВт·год і гривнях
- 📱 Телефон (нижня панель), 📟 планшет і ПК (бокове меню), темна/світла тема, українська

## Встановлення (Home Assistant OS)

1. **Налаштування → Застосунки (Add-ons) → Магазин → ⋮ → Репозиторії** → додати `https://github.com/vova275/itcity-home`
2. Встановити **ITCITY Home** → Запустити → «Показувати в боковому меню».

Токен не потрібен: застосунок говорить з HA через Supervisor, токен не потрапляє в браузер.

## Розробка

```bash
npm install
HA_URL=http://<ip-ha> HA_TOKEN=<long-lived-token> PORT=8099 node server.js   # бекенд
npm run dev                                                                   # фронтенд з HMR
```
